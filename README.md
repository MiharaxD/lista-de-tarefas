# 📝 Lista de Tarefas (To-Do List)

Projeto de uma lista de tarefas interativa, desenvolvido para praticar conceitos fundamentais do JavaScript, manipulação do DOM e persistência de dados no navegador.

---

## 📌 Funcionalidades

* **Gerenciamento de Tarefas:** Adicionar, concluir e remover itens da lista.
* **Armazenamento Local:** As tarefas ficam salvas no navegador (`localStorage`), mantendo os dados mesmo após atualizar ou fechar a página.
* **Interface Simples:** Layout limpo, intuitivo e focado na usabilidade.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura da aplicação.
* **CSS3:** Estilização e layout responsivo.
* **JavaScript:** Lógica de manipulação do DOM e integração com `localStorage`.
